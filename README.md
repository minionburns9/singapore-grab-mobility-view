# Singapore Grab Mobility View

Mobile-first prototype for Singapore ride-hailing and taxi intelligence.

## Views

1. Demand Heatmap
2. Taxi Demand Forecast
3. Nearby Mobility
4. Fare Shock / Surge Risk
5. Pickup Reliability
6. Event & Weather Disruption

## Tech Stack

- FastAPI
- Mapbox GL JS
- Render
- GitHub
